# PT 签到管家

作者及维护者：serendipity。版本：1.2.1。适用于 MoviePilot V2（>=2.15.6）和 V3（>=3.2.6）。

PT 站点签到、登录检测、奖励记录与访问记录核验。插件 ID 为 `PTSignInKeeper`，包名为 `ptsigninkeeper`，配置和数据使用独立命名空间。

## 功能

- 定时签到与登录核验，站点范围独立选择，失败重试与历史查询。
- HTTP、站点专用接口和浏览器适配；Browserless Token 可自由增删，去空去重。
- Browserless 站点白名单：仅所选站点允许直接调用或自动回退；清空即全部禁止，新增站点需手动勾选。
- 解析明确的当日奖励，保留各站币种，统一去除“个／点”等数量词。无法取得金额时显示“未获取”，与零奖励区分。
- 签到入口 HTTP 404 显示“入口暂不可用”，后续任务继续检查，不推断永久关闭。
- 可选 AI 辅助答题，使用 MoviePilot 智能助手配置；彩虹岛使用文字题，U2 需要视觉模型。未配置可用 AI 时，U2 随机选择，彩虹岛采用“不会”保底；AI 超时或答案不明确时不提交，提交后只读回查。
- 页面使用宿主原生主题和站点管理图标，支持分页、筛选、密度切换、按需详情与 CSV 导出。通知按摘要、异常与成功结果分层。

## 配置

在“整理 → PT 签到管家”打开页面，通过右上角设置选择站点与执行计划。AI 辅助在“答题签到”中开启；插件不单独保存 AI 密钥，仅发送题目、选项与必要题图。

在“浏览器与站点规则”填写 Browserless 地址、Token 和站点白名单。白名单按站点 ID 保存，不影响普通 HTTP、专用接口或本机 Playwright；勾选只授予 Browserless 使用权限，不会强制改用浏览器或自动加入签到范围。未配置或留空时禁止所有站点调用 Browserless，自定义规则不能绕过此限制。

登录有效仅代表会话可用，并不证明站点已更新访问时间。页面独立显示最近访问证据；AI 结果以站点反馈为准，可能答错。

首次启动支持读取本机旧 `AutoSignInPlus` 的缺失配置和历史，保留原记录，不重放立即执行或清理选项。迁移时先停用旧实例，避免重复任务；全新安装可直接配置。
