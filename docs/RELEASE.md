# v1.3.0 · 签到周期、通知与 Browserless 额度查询

作者及维护者：serendipity。PT 签到管家更新到 1.3.0，PT 邀请管家同步发行版本，功能不变。支持 MoviePilot V2 2.15.6 及以上版本和 V3 3.2.6 及以上版本。

## 更新内容

- Browserless Token 支持逐个或批量查询所属账户的剩余 units、本期已用、套餐额度和本期结束时间。使用官方只读账户接口，不创建浏览器；未保存的 Token 也能查询。结果缓存 1 分钟，同账户的多个 Token 不汇总额度，自建和第三方服务不向官方转发 Token。
- 签到和登录按一轮合并成一条通知，同站点去重。总览后依次展示需要处理、等待中的站点、实际奖励和仅登录结果；同类异常附处理提示，未变化的重试结果不重复推送。
- 奖励按站点分别列出，保留 0 奖励与未返回奖励的区别；已签到回执不会被描述为本轮新增收益。V2 文本通知与 V3 富文本通知保持相同内容。
- U2 凌晨保持待开放，北京时间 09:00 后检查默认页面日期与签到回执，避免把上一周期“今天已签到”算作今日完成。旧版没有周期证据的成功记录会重新核验，保留登录证据。
- 空站点配置给出明确提示；启用或保存后执行一次前必须选择至少一个签到或登录站点。手动执行也会检查站点范围。
- 兼容字符串站点 ID，避免保存时静默丢失；Cron 显式使用宿主时区，清除上次小时窗口的残留限制。

## 执行计划

每天北京时间 09:01 执行主任务：将宿主时区设置为 `Asia/Shanghai`，执行周期填写 `1 9 * * *`。每日失败重试时间是独立补跑计划；如果主任务在凌晨运行，建议保留 09:01 补跑。09:00 是插件对 U2 采用的保守检查时间，并非页面已确认的精确开放时刻。

## 安装

使用仓库对应 V2/V3 的源码目录或发行包。前端组件变化必须升级版本并刷新页面，不能覆盖已发布的同版本资源。

## 验证

覆盖空选、真实 APScheduler 单次调度、09:01 时区、字符串站点 ID、U2 凌晨到白天的周期切换与同日去重、合并通知计数和重复通知抑制。V2 与 V3 使用各自固定宿主镜像运行共享及兼容测试。

在隔离的 V2 2.15.6 环境，以三个已授权真实站点完成保存后执行、结果保存和同日去重验收。隔离宿主未配置 MoviePilot 认证，站点列表由测试输入提供；实际 HTTP、站点处理器、数据库与调度器均未模拟。网络验证使用现有 Cookie，不调用 AI 或发送渠道通知。凌晨与 09:01 的边界通过固定时钟回归验证，未等待下一日真实时刻。

Browserless 额度接口使用现有 Token 进行真实只读查询；回归覆盖缺失额度、零额度、错误脱敏、短缓存、编辑时丢弃旧响应、批量查询并发限制和 V2/V3 请求体接口兼容。
