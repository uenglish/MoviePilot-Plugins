# v1.1.0 · MoviePilot V2 兼容

作者及维护者：serendipity。本次为 PT 签到管家和 PT 邀请管家新增 MoviePilot V2 2.15.6 支持，继续支持 V3 3.2.6 及以上。更早的 V2 未验证，不声明兼容。

## 更新内容

- 两个插件均适配 V2 的配置、日志、数据库、网络、浏览器及插件接口；站点功能共用同一套源码。
- 保留原生主题、整理菜单入口、内嵌设置、搜索筛选、分页、折叠和密度切换。
- 签到 AI 答题复用 V2 智能助手配置；未配置可用 AI 时保留原有回退逻辑。
- V2 签到通知转换为按摘要、异常和成功结果分段的文本，隐藏不受支持的富文本开关。V3 通知行为保持不变。
- 增加 V2/V3 双版本生成校验与隔离回归检查。

## 安装与升级

在 MoviePilot 插件市场使用同一仓库，刷新后升级到 1.1.0。宿主按版本选择对应目录；手动安装时请选对安装包：

| 插件 | MoviePilot V2 | MoviePilot V3 |
| --- | --- | --- |
| PT 签到管家 | `ptsigninkeeper_mpv2_v1.1.0.zip` | `ptsigninkeeper_v1.1.0.zip` |
| PT 邀请管家 | `ptinvitekeeper_mpv2_v1.1.0.zip` | `ptinvitekeeper_v1.1.0.zip` |

包内包含源码、预构建前端、图标与许可文件。校验值见 `SHA256SUMS`。插件 ID 与配置命名空间保持不变；升级后刷新浏览器页面以加载新版本组件。

## 验证范围

451 项自动测试通过：两插件前端 25 项、V3 后端 209 项、V2 后端及宿主兼容检查 217 项。V2 原生接口与静态资源检查 34 项通过，其中包含 24 个 JS/CSS 资源。

已在隔离的 V2.15.6 原生前端验证两个独立页面、设置保存与回读、空列表筛选和分页控件、整页刷新。测试实例无 PT 站点认证，插件卡片弹窗未完成浏览器验收；没有执行真实站点签到、AI 请求或通知发送。真实站点结果仍取决于网络、账号状态和站点规则。
