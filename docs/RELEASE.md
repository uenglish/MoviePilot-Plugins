# v1.0.0 · 首次发布

作者及维护者：serendipity。适用于 MoviePilot V3 3.2.6 及以上。

本次发布包含两个独立插件：

- **PT 签到管家**：定时签到、登录与访问记录核验、奖励和币种识别、AI 辅助答题、动态 Browserless Token 列表、失败重试及历史查询。
- **PT 邀请管家**：邀请资格、永久与临时名额、成员状态、历史查询及异常重试。

两个插件采用统一的新图标，界面继承 MoviePilot 原生主题，侧栏位于“整理”分组，设置内嵌。提供搜索筛选、分页、折叠、密度切换、CSV 导出及层次清晰的通知。

奖励以明确的当日回执为准，缺失与零值分开显示；HTTP 404 标记为入口暂不可用，登录有效与保活证据分开记录。AI 辅助可能答错，结果以站点反馈为准。

安装包：`ptsigninkeeper_v1.0.0.zip`、`ptinvitekeeper_v1.0.0.zip`。校验值见 `SHA256SUMS`。每个安装包包含源码、预构建前端、图标和许可文件。

验证：签到后端 161 项、邀请后端 48 项；两插件前端测试、组件检查和构建；版本、资源与发布包检查。
