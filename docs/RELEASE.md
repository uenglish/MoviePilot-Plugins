# v1.4.0 · 界面重构、站点适配与邀请通知

作者及维护者：serendipity。PT 签到管家与 PT 邀请管家统一更新到 1.4.0。支持 MoviePilot V2 2.15.6 及以上版本和 V3 3.2.6 及以上版本。

## 页面与交互

- 签到与邀请页面统一为概况、状态筛选、站点记录三层；错误原因直接可见，历史与成员详情按需展开。
- 搜索框、下拉框、数字、密码和 JSON 输入统一聚焦样式，只在控件内显示一层边框；键盘操作保留明确的焦点提示。
- 设置按执行计划、站点范围等分组，支持目录定位和全部折叠；保存时锁定表单，失败保留输入，离开未保存设置时提示。
- 站点选择器每页最多展示 24 项；全选／清除搜索结果覆盖所有匹配页，旧站点选项保留。Browserless 白名单与管理全部站点的语义继续独立。
- 记录支持首尾页、页码跳转、10／20／50 条分页、紧凑与舒适密度；手机端采用紧凑卡片，附加筛选按需展开。
- 概况折叠和分页偏好按插件保存；详情缓存限制大小，筛选变更丢弃旧响应，设置打开时暂停任务轮询，导出避免重复请求。

## 站点适配

- Sunny 使用 Cookie 换取会话令牌，再读取状态和调用签到 API；登录仅验证会话，不触发签到；未知奖励与零奖励分开处理。
- 躺平使用普通 HTTP 表单，保留隐藏校验字段及同一会话 Cookie，提交一次后回读确认；不将失败自动转给浏览器重复提交。
- 专用站点模块采用稳定导入，重新扫描不创建重复模块身份，保证周期判断与运行状态一致。
- 保留现有 U2 周期校验、皇后默认浏览器路径与 Browserless 白名单。宿主通用登录检测和馒头 Token 保活仍作为独立后续工作。

## 邀请通知

- 通知标题突出读取失败、需关注站点与本次变化；正文按摘要、变化、读取异常、成员状态、现有名额与兑换估算排列。
- 直接比较刷新前后记录，合并同站变化，写明永久／临时名额和成员数量增减；首次记录与失败恢复独立处理，不用历史缺省零值生成虚假变化。
- 区分现有可用名额、兑换估算、未知数量和资格受限；成员按分站记录统计，已禁用、低分享率及分享率待确认分别展示。
- 失败缓存排除在当前统计之外，常见故障提供处理建议；缓存预览注明记录时间，不冒充新一轮刷新。
- V2/V3 使用同一内容模型，V2 邀请通知使用独立桥接模块；通知详情有总长度与分段条数限制。

## 升级与安装

通过插件市场更新到 1.4.0 后刷新页面，以加载新前端资源。也可使用对应 V2/V3 源码目录或发行包；文件名含 `mpv2` 的 ZIP 用于 V2，其余用于 V3。发行包含四个 ZIP 和 `SHA256SUMS`，两个插件可独立安装。

## 验证与已知限制

- 前端逻辑、V2/V3 后端和宿主兼容回归通过。两个插件的生产构建、共享资源检查和 V2 派生源码一致性检查通过。
- 生产前端资源通过 28 项交互检查，以及 V2/V3、两款插件、深浅主题和四种宽度组合的 32 项布局检查。浏览器验收使用宿主样式与模拟站点数据，不触发实际签到或通知。
- 在隔离 V2 2.15.6 环境，使用三个已授权真实站点验证保存后执行、登录、结果入库和同日去重；HTTP、站点处理器、数据库与调度器均未模拟。验证未发送渠道通知。
- Sunny 暂无可用测试账号，完成协议与异常回归；躺平真实签到页 GET 超时，未提交表单。两站尚未完成真实签到成功验证，网络故障不会记为成功。
