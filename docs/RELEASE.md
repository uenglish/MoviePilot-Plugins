# v1.2.0 · Browserless 站点白名单

作者及维护者：serendipity。本次更新 PT 签到管家，PT 邀请管家同步仓库发行版本。继续支持 MoviePilot V2 2.15.6 及以上版本和 V3 3.2.6 及以上版本。

## 更新内容

- Browserless 设置新增可搜索的站点白名单。仅明确勾选的站点可以调用 Browserless；未配置或清空时全部禁止，新站点不会自动获得权限。
- 白名单统一约束直接调用、HTTP 与 API Key 防护回退，以及本机 Playwright 失败后的云端回退。普通 HTTP、站点专用接口和成功的本机 Playwright 不受影响；自定义规则不能绕过限制。
- 配置迁移保留已保存的站点 ID；V2/V3 前后端均使用显式站点选择。修复 V2 `RequestUtils` 会话兼容，并避免自动重试未变化时重复发送相同通知。
- PT 邀请管家仅同步到 1.2.0，功能无变化。

## 安装与升级

在 MoviePilot 插件市场使用同一仓库，刷新后升级到 1.2.0。手动安装时请根据宿主版本选择对应安装包：

| 插件 | MoviePilot V2 | MoviePilot V3 |
| --- | --- | --- |
| PT 签到管家 | `ptsigninkeeper_mpv2_v1.2.0.zip` | `ptsigninkeeper_v1.2.0.zip` |
| PT 邀请管家 | `ptinvitekeeper_mpv2_v1.2.0.zip` | `ptinvitekeeper_v1.2.0.zip` |

包内包含源码、预构建前端、图标与许可文件。校验值见 `SHA256SUMS`。升级后刷新浏览器页面以加载新设置组件。

## 验证范围

493 项自动化检查通过：前端 28 项、V3 后端 228 项、V2 后端与宿主兼容 237 项。包含 V2/V3 两代运行时测试、发行目录生成检查和前端资源构建校验。白名单回归使用假网络客户端；没有执行真实站点签到、AI 请求或通知发送。

V2 最低兼容版本为 2.15.6，V3 最低兼容版本为 3.2.6。真实站点结果仍取决于网络、账号状态和站点规则。
