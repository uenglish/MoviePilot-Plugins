# 版本说明

两个插件独立维护版本号和发行记录。同一插件的 V2/V3 版本保持一致，安装包可独立使用。

| 插件 | 当前版本 | 发行说明 |
| --- | --- | --- |
| PT 签到管家 | 1.4.4 | [签到回执与登录验证修复](releases/PTSignInKeeper_v1.4.4.md) |
| PT 邀请管家 | 1.4.1 | [原生 JSON 仪表板](releases/PTInviteKeeper_v1.4.1.md) |

新发行标签使用 `PTSignInKeeper_vX.Y.Z` 或 `PTInviteKeeper_vX.Y.Z`，每个发行包含对应插件的 V2/V3 ZIP 和 `SHA256SUMS`。市场仍按各插件索引中的版本检查更新。

历史统一发行版及其附件继续保留；[v1.4.0 版本说明](releases/v1.4.0.md)记载了拆分前的更新内容。
