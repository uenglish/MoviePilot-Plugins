# MoviePilot V2 兼容

兼容目标为 MoviePilot V2 2.15.6。更早版本未验证，不保证能加载全部页面和宿主接口。

## 安装与功能

同一仓库提供 `package.v2.json`、`plugins.v2/` 和现有 V3 目录。两版保持相同插件 ID、作者和配置命名空间。V2 ZIP 文件名包含 `mpv2`。

- 保留 Vue 页面、整理菜单、内嵌设置、站点图标、筛选、分页、折叠与导出。
- V2 使用原生配置、日志、数据库、HTTP、OCR 和浏览器接口。
- 签到 HTTP 会话显式保留重定向和表单返回的 Cookie，支持站点轮换、过期、路径与域名限制；更换配置 Cookie 时清除旧会话。
- AI 复用 V2 智能助手的提供商、模型及视觉能力信息。未配置 AI 时保留现有随机／不会流程；不清空用户 AI 设置。
- V2 没有 V3 的结构化通知对象，签到与邀请结果转换为保留相同摘要、段落和顺序的文本，页面隐藏富文本通知开关。每个插件使用自己的通知桥接模块，可独立安装。

## 维护与验证

V2 运行文件由同一套 V3 功能源码生成，仅转换宿主导入路径并加入通知、AI 桥接。`scripts/build_v2.py --check` 检查所有生成文件，阻止站点修复只进入一个版本。

两个插件独立发行，同一插件的 V2/V3 版本保持一致。签到管家更新不改变邀请管家的版本或安装包。

`scripts/test_v2.sh` 使用固定的官方 V2 镜像摘要，网络关闭、临时数据库、无生产目录挂载，运行共享业务测试和 V2 专用宿主测试。真实站点的访问结果仍取决于部署实例的网络、Cookie、站点规则与模型配置。
