# PT 签到管家 1.4.2 · 杜比新域名任务遗漏修复

作者及维护者：serendipity。本次更新 PT 签到管家至 1.4.2，提供 V2/V3 两个平台包。V2 已验证版本为 2.15.6，V3 支持 3.2.6 及以上。邀请管家保持 1.4.0。

## 修复内容

- 修复杜比新域名 `uhddolby.com` 已配置、已选中，却没有执行日志和签到结果的问题：V2 原生索引器未收录新域名，旧任务构建流程因此遗漏该账号。
- 签到、登录和域名调用改为直接读取已配置的站点账号及连接设置，不再依赖宿主搜索索引器的域名规则。保留用户选择、停用与公开站点过滤、自定义站点合并和同日结果去重。
- 每个站点开始执行时记录站点名称和 ID，便于区分未执行与执行失败；日志不包含 Cookie、Token 等凭据。

## 安装与验证

在插件市场更新 PT 签到管家即可。手动安装时，文件名含 `mpv2` 的 ZIP 用于 V2，其余用于 V3。本次独立发行标签为 `PTSignInKeeper_v1.4.2`，附件仅包含签到管家的两个平台包与 `SHA256SUMS`。

已在 V2 2.15.6 中使用原生站点发现、隔离数据库与真实杜比账号完成前后对照：1.4.1 未发起请求且没有结果；修复后通过普通 HTTP 读取今日已签回执，保存签到与登录结果，再次执行不新增请求。测试关闭 Browserless，未发送通知，也没有提交新的签到表单，因此尚未覆盖真实站点当天首次签到。

新增 7 项共享回归覆盖新域名任务、连接参数、站点筛选与去重、域名调用和日志。完整发行检查共 646 项测试通过，覆盖两款插件前端、V2/V3 业务、V2 宿主兼容与发行脚本；前端构建和 V2 生成一致性校验通过。

宿主站点卡片的上传下载统计、搜索和图标规则由 MoviePilot 自身维护。本次修复解决插件任务遗漏，不改变宿主统计行为。
