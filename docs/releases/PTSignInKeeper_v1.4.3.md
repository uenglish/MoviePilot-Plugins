# PT 签到管家 1.4.3 · 首页卡片与原生 JSON 仪表板

作者及维护者：serendipity。提供独立的 V2/V3 安装包，V2 已验证版本为 2.15.6，V3 支持 3.2.6 及以上。

## 更新内容

- 首页新增“PT 签到管家”卡片，显示当日签到、登录、需处理和待完成统计，以及最多 3 个站点摘要。
- 标准 `get_dashboard()` 返回非空原生 JSON，网页卡片复用同一份数据。总体统计不受预览条数限制，停用站点不混入当前总数。
- 保留 U2 待开放和未确认状态、仅登录站点与无签到功能的区别。奖励按站点保留币种，零奖励和未获取分别显示。
- 打开和刷新卡片只读取已保存记录，不触发签到、站点访问或通知。读取失败保留原内容，宿主更新不会被旧请求覆盖。

## iOS 兼容边界

**本次提供原生 JSON 输出，不代表 MoviePilot for iOS 2.0.2 的首页显示问题已经解决。** V2/V3 宿主仍从插件整体模式返回 `render_mode: "vue"`，iOS 2.0.2 会直接显示 Vue 占位说明，不会使用非空 `elements`。完整页面、设置与侧栏继续使用现有 Vue 页面。

后续仍需宿主提供独立仪表板模式，或客户端支持原生 JSON 回退。详细说明见 [兼容文档](https://github.com/uenglish/MoviePilot-Plugins/blob/PTSignInKeeper_v1.4.3/docs/COMPATIBILITY.md)。

## 安装与验证

在插件市场更新 PT 签到管家，并在首页添加“PT 签到管家”卡片。手动安装时，文件名含 `mpv2` 的 ZIP 用于 V2，其余用于 V3。标签 `PTSignInKeeper_v1.4.3` 仅包含本插件的两个平台包与 `SHA256SUMS`；邀请管家独立维护版本和发行附件。

已验证两套真实宿主的 JSON 组装结果一致；回归覆盖空数据、全局统计、站点筛选、奖励与 U2 周期、只读行为。浏览器验收覆盖 V2/V3 构建产物、320–1280 像素、明暗主题、长名称、重试、宿主更新与卸载。浏览器中的 JSON 预览不等于 iOS 真机验证。
