# PT 邀请管家 1.4.1 · 原生 JSON 仪表板

作者及维护者：serendipity。提供独立的 V2/V3 安装包，V2 已验证版本为 2.15.6，V3 支持 3.2.6 及以上。

## 更新内容

- 标准 `get_dashboard()` 返回非空原生 JSON，包含站点记录、可邀请站点、需处理站点和已知持有名额统计，以及最多 3 个站点摘要。
- 名额未知和零值分别显示；刷新失败保留的旧值标明“上次记录名额”，并排除在名额与成员汇总之外。较旧记录提示重新核验。
- 更新时间使用宿主配置时区。摘要不包含成员身份、邮箱或连接凭据；读取仪表板只使用本地快照，不访问站点或发送通知。
- 网页端沿用现有邀请卡片，完整页面、设置与侧栏继续使用现有 Vue 页面。

## iOS 兼容边界

**本次提供原生 JSON 输出，不代表 MoviePilot for iOS 2.0.2 的首页显示问题已经解决。** V2/V3 宿主仍返回 `render_mode: "vue"`，iOS 2.0.2 会直接显示 Vue 占位说明，不会使用非空 `elements`。

后续仍需宿主提供独立仪表板模式，或客户端支持原生 JSON 回退。详细说明见 [兼容文档](https://github.com/uenglish/MoviePilot-Plugins/blob/PTInviteKeeper_v1.4.1/docs/COMPATIBILITY.md)。

## 安装与验证

在插件市场更新 PT 邀请管家即可。手动安装时，文件名含 `mpv2` 的 ZIP 用于 V2，其余用于 V3。标签 `PTInviteKeeper_v1.4.1` 仅包含本插件的两个平台包与 `SHA256SUMS`；签到管家独立维护版本和发行附件。

已验证两套真实宿主的 JSON 组装结果一致；回归覆盖空数据、全局统计、未知与零名额、失败缓存、更新时间、只读行为和成员隐私。原生 JSON 已用真实 Vuetify 组件验证明暗主题与窄屏布局，尚未通过 iOS 真机渲染验证。
