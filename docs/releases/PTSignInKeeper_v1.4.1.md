# PT 签到管家 1.4.1 · V2 会话与签到回执修复

作者及维护者：serendipity。本次更新 PT 签到管家至 1.4.1，提供 V2/V3 两个平台包。V2 已验证版本为 2.15.6，V3 支持 3.2.6 及以上。

## 修复内容

- 修复 V2 HTTP 会话丢失重定向和表单 Cookie 的问题，正确处理 Cookie 轮换、过期、路径和域名差异；更换配置 Cookie 时清除旧会话。
- Depth Studio 默认先使用 HTTP 读取签到页，正常回执无需配置 Browserless；遇到验证时仍遵守原有回退规则和白名单。
- 彩虹岛根据独立的今日回执判断完成，即使页面保留答题表单也不再重复提交。奖励只从确认回执读取，避免把规则说明中的金额当作实际收益。

## 独立发行

签到与邀请管家开始独立维护版本和发行记录。本次标签为 `PTSignInKeeper_v1.4.1`，附件仅包含签到管家的 V2/V3 ZIP 与 `SHA256SUMS`。邀请管家保持 1.4.0；历史统一发行版继续保留。

## 安装与验证

在插件市场更新 PT 签到管家即可。手动安装时，文件名含 `mpv2` 的 ZIP 用于 V2，其余用于 V3。

V2 共享业务与宿主兼容共 303 项回归通过；其中 11 项使用真实 V2 HTTP 客户端对本地服务验证会话、重定向和单次表单提交。V3 签到 216 项回归通过。

杜比、Depth Studio、彩虹岛已完成真实 V2 回执复核，杜比及 Depth Studio 在关闭 Browserless 后通过。已签到回执不等同于测试当天首次提交；杜比真实首次提交尚未覆盖。站点入口 404、服务端 500 和网络超时仍按实际失败记录。
