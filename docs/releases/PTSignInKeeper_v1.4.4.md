# PT 签到管家 1.4.4 · 签到回执与登录验证修复

## 更新内容

- 修复杜比账号密码登录页被误报为异地验证的问题。遇到登录表单会提示检查 MoviePilot 所在网络的站点会话，遇到独立的二次验证页会提示人工完成验证。U2 账号导航中的“两步验证”链接也能正确识别。
- 憨憨、烧包和麒麟使用内置规则时，即使站点在 Browserless 白名单外，插件也会通过普通 HTTP 读取当前账号的当日签到回执和奖励。遇到待提交表单、人工验证或站点错误时，结果中会保留具体原因。
- 海胆在同一会话中读取首页、调用签到入口并回查打卡按钮。每轮最多调用一次签到入口，响应中断后通过首页确认结果。
- 登录失败时区分请求超时、代理错误、TLS 错误和连接中断。超时提示包含站点配置的秒数。

## 验证范围

在 MoviePilot V2 2.15.6 上，使用真实账号确认了杜比的 166 鲸币、憨憨的 50 憨豆和麒麟的 170 魔力值回执，以及 U2 首页的登录状态。烧包较早返回的真实页面记录了 50 魔力值，在同一版本宿主回放时成功保存并导出。后续在线复测中，烧包返回 HTTP 500。

实站签到验证覆盖当日已有回执，当天首次提交仍待验证。海胆通过了本地 HTTP 服务的会话轮换、重定向和断线回查测试，真实账号验证仍待补充。

## 安装

在 MoviePilot 插件市场将 **PT 签到管家** 更新至 **1.4.4**。手动安装时，MoviePilot V2（2.15.6 及以上）使用 `ptsigninkeeper_mpv2_v1.4.4.zip`，MoviePilot V3（3.2.6 及以上）使用 `ptsigninkeeper_v1.4.4.zip`。两个安装包的校验值见 `SHA256SUMS`。
