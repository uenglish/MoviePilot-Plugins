# PT 邀请管家

作者及维护者：serendipity。版本：1.4.0。适用于 MoviePilot V2（>=2.15.6）和 V3（>=3.2.6）。

PT 邀请资格、可用名额和成员状态管理。插件 ID 为 `PTInviteKeeper`，包名为 `ptinvitekeeper`，配置和数据使用独立命名空间。

## 功能

- 定时读取邀请资格、永久与临时名额、成员状态，提供异常重试和历史查询。
- 可用名额仅统计当前可邀请站点；受限站点和失败缓存单独标记，未知值与零值区分。
- 页面继承 MoviePilot 原生主题和站点管理图标，支持搜索筛选、分页、折叠、密度切换与 CSV 导出。
- 通知先展示摘要与本次变化，再列读取异常、成员关注、现有名额、兑换估算与邀请限制，支持缓存预览。
- 独立的邀请函图标，侧栏使用信封加号，设置内嵌在页面中。
- 首页仪表板同时提供标准原生 JSON，展示邀请概况与最多 3 个站点摘要。未知名额保留“未知”，刷新失败后保留的旧值单独注明，不包含成员身份或邮箱；读取仪表板不会访问站点。

原生 JSON 仪表板目前为兼容试验：MoviePilot for iOS 2.0.2 仍会根据整个插件的 `vue` 模式显示占位说明，不会自动使用这些 JSON。详见仓库的 `docs/COMPATIBILITY.md`，此改动不代表 iOS 首页显示问题已经解决。

## 配置

在“整理 → PT 邀请管家”打开页面，通过右上角设置选择站点与刷新计划。首次启用后读取站点数据；读取失败保留历史值并注明缓存状态。

首次启动支持读取本机旧 `NexusInviteePlus` 的缺失配置和历史，保留原记录，不重放立即执行或清理选项。迁移时先停用旧实例，避免重复任务；全新安装可直接配置。

## 邀请通知

启用“发送通知”后，每次刷新按实际选中的站点生成一份简报。标题区分读取失败、需要关注、发生变化和普通更新；没有变化也正常通知。

- “本次变化”直接比较刷新前后的记录，同一站点合并资格、永久／临时名额、成员数量和健康分类变化。首次记录不视为名额增加；失败恢复只提示读取恢复，不将旧缓存当作上轮成功结果。
- 现有可用名额只包含当前确认可邀请的站点，永久与临时分别列出。未知数量不填零，部分缺失只汇总已知数量；等级受限等站点的持有名额不计入可用总数。
- 可兑换名额按当前魔力和价格估算，尚未持有，不与现有名额合计。同站永久／临时方案共用余额，不能相加，最终以站点规则为准。
- 读取失败提供处理建议，保留历史记录但排除其名额与成员统计；读取成功但资格不明确单独标为待确认。
- 成员总数使用分站记录数，不声称跨站去重；同一站内的已禁用、低分享率和分享率待确认互斥。通知不包含成员身份、邮箱或凭据。
- 各段最多列出 6 站，长通知同时限制详情总长度，并保留省略数量和页面入口。V3 结构化内容与 V2 分段文本使用同一份内容。

手动预览只读取已存记录，注明缓存时间，不访问站点、不修改通知开关或计划；点击预览会向现有通知渠道发送一条预览消息。

## 界面与操作

概况、站点记录、成员详情与设置采用统一布局；搜索、下拉框和输入框使用同一层聚焦反馈。手机端的“筛选”按钮按需展开附加条件。概况可折叠，记录支持分页和密度切换，设置支持目录定位和分组折叠。成员统计表示分站记录，不等同跨站去重人数。

站点选择器每页 24 项，批量选择覆盖全部匹配结果。管理站点留空仍表示全部，界面明确提示这一保存语义；已有但暂时未加载的站点选项继续保留。
