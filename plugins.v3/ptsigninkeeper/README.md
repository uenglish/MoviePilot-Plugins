# PT 签到管家

作者及维护者：serendipity。版本：1.4.0。适用于 MoviePilot V2（>=2.15.6）和 V3（>=3.2.6）。

PT 站点签到、登录检测、奖励记录与访问记录核验。插件 ID 为 `PTSignInKeeper`，包名为 `ptsigninkeeper`，配置和数据使用独立命名空间。

## 功能

- 定时签到与登录核验，站点范围独立选择，失败重试与历史查询。
- HTTP、站点专用接口和浏览器适配；Browserless Token 可自由增删，去空去重。
- Browserless Token 可逐个或批量查询账户剩余 units、本期用量、套餐额度及本期结束时间；未保存的 Token 也可查询。
- Browserless 站点白名单：仅所选站点允许直接调用或自动回退；清空即全部禁止，新增站点需手动勾选。
- 解析明确的当日奖励，保留各站币种，统一去除“个／点”等数量词。无法取得金额时显示“未获取”，与零奖励区分。
- 签到入口 HTTP 404 显示“入口暂不可用”，后续任务继续检查，不推断永久关闭。
- 可选 AI 辅助答题，使用 MoviePilot 智能助手配置；彩虹岛使用文字题，U2 需要视觉模型。未配置可用 AI 时，U2 随机选择，彩虹岛采用“不会”保底；AI 超时或答案不明确时不提交，提交后只读回查。
- 页面使用宿主原生主题和站点管理图标，支持分页、筛选、密度切换、按需详情与 CSV 导出。通知每轮合并签到与登录结果，按总览、需要处理、等待、各站奖励分段；同站点计数去重，未变化的自动重试不重复推送。

## 配置

在“整理 → PT 签到管家”打开页面，通过右上角设置选择站点与执行计划。AI 辅助在“答题签到”中开启；插件不单独保存 AI 密钥，仅发送题目、选项与必要题图。

在“浏览器与站点规则”填写 Browserless 地址、Token 和站点白名单。白名单按站点 ID 保存，不影响普通 HTTP、专用接口或本机 Playwright；勾选只授予 Browserless 使用权限，不会强制改用浏览器或自动加入签到范围。未配置或留空时禁止所有站点调用 Browserless，自定义规则不能绕过此限制。

点击 Token 旁的“查额度”或“查询全部额度”，读取 Browserless 官方账户数据。查询不启动浏览器、不保存设置，结果缓存 1 分钟；修改 Token 或服务地址会清除旧结果。额度归所属账户，同账户的多个 Token 共享额度，不能将每行结果相加；缺失字段显示“未知”，剩余值以官方返回为准。仅支持官方云服务，自建或第三方服务请查看各自控制台。

登录有效仅代表会话可用，并不证明站点已更新访问时间。页面独立显示最近访问证据；AI 结果以站点反馈为准，可能答错。

首次启动支持读取本机旧 `AutoSignInPlus` 的缺失配置和历史，保留原记录，不重放立即执行或清理选项。迁移时先停用旧实例，避免重复任务；全新安装可直接配置。

## 执行计划与 U2

启用或“保存后执行一次”前，至少选择一个签到或登录站点；两项为空不会执行，也不会自动扩大为全部站点。每天北京时间 09:01 执行主任务可填写 `1 9 * * *`（宿主时区为 Asia/Shanghai）；“每日失败重试时间”是独立的补跑计划。

U2 以北京时间 09:00 后核验当日周期：凌晨标记为待开放，不把上一周期“今天已签到”算作当天完成；白天同时核对默认签到页日期和完成回执。建议保留 09:01 的每日补跑。升级前未保存周期日期的 U2 成功记录会重新核验，登录证据保留。09:00 是插件的保守核验时间，并非从页面确认的精确开放时刻。

通知中的奖励按站点分别展示，不合计不同币种；“已签到”的奖励回执不代表本轮新增收益。仅登录站点独立统计，登录有效不等同于已确认保活。

## 界面与站点流程

- 列表上方展示运行概况，点击统计值可筛选；可收起概况并记住选择。手机端的“筛选”按钮展开日期、状态和排序。
- 分页支持每页 10／20／50 条、首尾页和桌面端页码跳转；站点详情及历史按需读取，切换筛选时不会混入旧请求结果。
- 设置支持分组折叠和目录定位。站点选择器每页 24 项，“全选结果／清除结果”作用于全部匹配结果。Browserless 白名单留空仍表示禁止调用。
- Sunny 使用专用会话和签到 API；登录操作不签到，未知奖励不填成 0。躺平使用普通 POST 签到表单，携带隐藏字段与会话，提交后回读确认。
- U2 仍按现有站点周期核验；不因为凌晨的旧周期回执计入今日完成。
